## Description
The SCEC Ground Motion Simulation Validation (GMSV) software Toolkit that provides standardized tools for ground motion simulation validation.

## Installation

### Dependencies

In order to install and run the GMSV Toolkit software, users will need to have the following dependencies installed:

* Python v3.8.18+ with
  * Matplotlib 3.7.5+
  * NumPy 1.24.4+
  * SciPy 1.10.1+
 * GNU compilers (gcc, gfortran) 13.3+
  * FFTW library 3.3.8

## Support
Support for GMSV Toolkit is provided by the Statewide California Earthquake Center (SCEC) Research Computing Group.
